## A source-first audit route

Read the abstract and scenarios on p. 1, inspect Figure 1 and the pillar sequence on pp. 2-4, then read p. 5's employment example separately from the framework. Finish with p. 6 and ask which cited item supports each important assertion. Use [claim metadata](../metadata/claims.json) as an index, then return to the source for context. The metadata is a navigation aid, not a substitute for reading.
